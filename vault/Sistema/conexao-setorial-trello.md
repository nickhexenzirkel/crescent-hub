O módulo **Conexão Setorial** (`src/modules/conexao-setorial/index.jsx`) foi reescrito (jul/2026): **deixou de ser o chat estilo WhatsApp** (grupo/DMs/comandos mock) e virou um **quadro Kanban estilo Trello** do time do Financeiro, com estética Uniko (gradiente rosa/roxo `#E0559A→#A24CE0`).

- **Real e compartilhado via Supabase + realtime** — tabelas `conexao_lists` e `conexao_cards`. **PRECISA rodar `supabase_conexao_setorial_trello.sql`** (cria tabelas, políticas RLS permissivas p/ anon, adiciona no `supabase_realtime` e semeia 4 colunas: A Fazer / Em Andamento / Em Revisão / Concluído). Sem rodar, o quadro aparece VAZIO (o código trata a tabela ausente com graça) e criar coluna falha.
- **jul/2026: acesso liberado pra todo mundo** (era admin-only + uma lista de CPFs — ver [[conexao-setorial-salas]] pro detalhe). O componente usa o `authUser` real (antes ignorava, com `ME='nicolas'` mock).
- **Funcionalidades:** arrastar-e-soltar nativo (cards entre colunas + reordenar), colunas criáveis/renomeáveis/removíveis; cards com prazo (badge vencendo/atrasado), prioridade, etiquetas por setor, **responsáveis vindos de `/api/employees`** (server admin), checklist com barra de progresso e comentários; filtros por texto/responsável/etiqueta.
- **Notificação desktop + som:** usa `notifyDesktop` (utils/desktopNotify → extensão Cat-bot / Web Notifications, ver [[notificacoes-desktop]]) + um chime via WebAudio (`playChime`, sem arquivo). Dispara quando te atribuem um card, comentam em card teu/atribuído a ti, ou um prazo vence/atrasa (varredura a cada 60s). Toggle 🔔 no header (localStorage `cs_notif`); permissão pedida no clique do toggle (gesto).
- Sincronização: realtime nas duas tabelas + poll de 20s como rede de segurança. Escritas otimistas (atualiza local antes do banco).
- **Imagens nos cards (jul/2026):** seção "Imagens" no modal com drop zone que aceita **arrastar arquivo, colar (Ctrl+V)** e clique; sobem pro **Supabase Storage bucket `conexao`** (público) e ficam no jsonb `images` do card (`{url,path,name}`). Capa da 1ª imagem no card do quadro + contador + grid com remover + lightbox. **PRECISA rodar `supabase_conexao_setorial_images.sql`** (add coluna `images`, cria o bucket + policies do storage.objects, e tira os emojis dos títulos de coluna padrão).
- **Ícones SVG:** todos os emojis da UI viraram ícones SVG traço (componente `Ic` + `ICON_PATHS` no topo do arquivo). Os títulos de coluna padrão também perderam os emojis (viraram ícones/texto).
- **Menu de contexto no card (jul/2026):** botão direito num card do quadro abre um menu (`ctxMenu` state no `Board`) com "Mover para" (submenu com as outras colunas, via `moveCardToList`), "Arquivar" e "Excluir" (com confirm) — sem precisar abrir o modal do card antes. Fechado por overlay full-screen (clique fora ou botão direito de novo).
- **Trancar coluna (jul/2026):** botão direito no espaço vazio de uma coluna (`ctxMenuList` state) abre menu com "Trancar/Destravar coluna" (`toggleLockList`). Coluna trancada (`list.locked`) esconde o X de excluir e `deleteList` também bloqueia no backend caso seja chamado por outro caminho. **PRECISA rodar `supabase_conexao_setorial_lock_list.sql`** (coluna `locked boolean default false` em `conexao_lists`).
- **Diff no histórico (jul/2026):** alterar título ou descrição agora grava `{before, after}` (texto puro, sem HTML) dentro do item do `history`. No feed "Comentários e atividade", esses itens ganham um link "Clique para ver" que expande um antes/depois com diff palavra-a-palavra (`diffWords`, LCS simples) — vermelho riscado = saiu, verde negrito = entrou.
- **BUG (jul/2026, 2 tentativas até resolver de vez): editar a descrição perdia texto no meio da digitação.** O editor (`contentEditable` no `CardModal`) usava `dangerouslySetInnerHTML` amarrado direto no `card.description` AO VIVO — como o quadro sincroniza o tempo todo (qualquer mudança em QUALQUER card do board gera uma nova referência do array `cards`, via `postgres_changes`/poll de 20s), a cada atualização o React reaplicava o HTML antigo do banco por cima do que a pessoa estava digitando.
  - **1ª tentativa (insuficiente):** snapshot local (`descSnapshot`) capturado só no instante em que `editDesc` vira `true`, renderizado via `dangerouslySetInnerHTML={{__html: descSnapshot}}` (que em teoria o React só reaplica se a STRING mudar). Dois colaboradores diferentes confirmaram que o bug continuava acontecendo mesmo depois de deploy forçado + hard refresh — ou seja, não era cache/deploy, tinha algo realmente reescrevendo o innerHTML.
  - **Fix definitivo:** tirou o `dangerouslySetInnerHTML` de vez do editor. Agora um `useEffect` com dep `[editDesc]` escreve `descRef.current.innerHTML = card.description` IMPERATIVAMENTE, uma única vez, só na transição pra `true`. Como o React não sabe mais de nenhum valor de `__html` pra comparar/reaplicar naquele elemento, é estruturalmente impossível qualquer re-render (por realtime, poll, ou qualquer outro motivo) sobrescrever o que a pessoa está digitando — não depende mais de nenhuma suposição sobre reconciliação do React. `saveDesc` continua comparando contra `card.description` ao vivo pra decidir se há algo novo a salvar.
  - Mesma classe de bug já documentada no Uniko Paint (`aplicaEstado`/guarda de `ts`), só que aqui o vetor era o editor de um campo de texto, não um estado de partida.
- **BUG (set/2026): descrição colada de fonte escura ignorava o tema claro.** Colar texto de um editor/terminal com fundo escuro trazia `style` inline (background-color/color) que sobrepunha o tema do Trello — texto claro em fundo preto mesmo no tema claro, inclusive em cards já salvos. Fix: helper `stripInlineColors` (remove `style=`/`bgcolor`/`<font color>`) aplicado ao salvar, carregar no editor e exibir a descrição — corrige também descrições antigas já quebradas, sem precisar reeditar.
- **Descrição expandida + comentários ao lado (set/2026):** clicar numa descrição preenchida abre um overlay maior (`descExpanded` state no `CardModal`) com o texto inteiro sem scroll lateral (word-wrap). Um botão flutuante de comentário (`expComments`) abre o feed de "Comentários e atividade" como coluna ao lado da descrição (alarga o modal, não cobre o texto — 1ª versão flutuava por cima e tampava a descrição, corrigido no mesmo dia). Lógica do feed extraída pra `renderFeed()` dentro do `CardModal` pra não duplicar entre a coluna normal e essa barra.
